# Модуль `realtime`

**Отвечает за:** мгновенную доставку событий в браузер — новые сообщения в темах, рецензии по
интересам, общие чаты.
**URL:** `/ws` (WebSocket) · **Код:** `modules/realtime/`

**Статус:** WebSocket-заглушка (echo): возвращает клиенту его же сообщения. Нужна, чтобы проверить,
что WebSocket проходит через nginx. Ручная проверка — `http/realtime.http`.

## Таблицы

Своих таблиц нет и не планируется. `realtime` — это транспорт: данные создают другие модули
(`social` сохраняет сообщение в БД), а `realtime` только доставляет событие подписанным клиентам.

## Как будет работать 🕓

```
пользователь пишет в тему ──► social: сохранить в БД ──► опубликовать событие
                                                                │
                                                                ▼
                       realtime: кому это интересно? (user_interests, участники темы)
                                                                │
                                                                ▼
                                           отправить по открытым WebSocket'ам
```

1. Клиент открывает `/ws` с access-токеном. `realtime` проверяет токен и узнаёт пользователя.
2. Клиент подписывается на каналы: свои интересы (`entity:<id>`), открытую тему (`thread:<id>`),
   личные уведомления (`user:<id>`).
3. Другие модули публикуют события, а `realtime` рассылает их подписчикам канала.

**Шина событий:**
- Один экземпляр приложения — `tokio::sync::broadcast` внутри процесса, без внешних зависимостей.
- Несколько экземпляров за балансировщиком — Redis pub/sub, чтобы событие с одного экземпляра дошло
  до клиентов, подключённых к другому.

Модули не вызывают `realtime` напрямую (это нарушило бы [границы модулей](../architecture.md#правила-границ)).
Они публикуют событие через интерфейс из `shared`, а `realtime` на него подписан. Предложение
трейта и событий форума — в [social.md](social.md#realtime-новые-сообщения--предложение-не-реализовано).

## Формат сообщений 🕓

JSON с типом события, например:

```json
{ "type": "thread.post_created", "thread_id": "…", "post": { "id": "…", "author": "…", "body": "…" } }
```
