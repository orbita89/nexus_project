# Промпт для фронтенда: полные титры и новые данные карточки

Задача для сессии фронтенда (`/home/dev/nexus_web`). Бэкенд не менять: если в API чего-то не
хватает — записать в `docs/backend-questions.md`.

---

## Контекст

С 2026-10-14 каталог — только фильмы TMDB (сидов, сериалов, книг и игр на dev больше нет), и по
каждому фильму на сайте загружены полные данные TMDB. Схемы API **не менялись**, но изменилось
содержимое:

1. **Титры (`credits` в `GET /api/v1/catalog/entities/{slug}`) стали полными.** Раньше — режиссёр и
   до 15 актёров; теперь — режиссёры, сценаристы, продюсеры, композиторы, операторы, монтажёры и
   **весь** актёрский состав (у популярных фильмов — 100+ актёров). Порядок: по ролям, внутри роли —
   `position` (у актёров — порядок в титрах TMDB, главные первыми).
2. **Новые значения `role`:** `producer`, `cinematographer`, `editor` (раньше встречались только
   `director`, `actor`, `writer`, `composer`, `voice_actor`, `author`, `creator`).
3. Чаще заполнены `description`, `cover_url`, `metadata.runtime_min`, `metadata.countries`,
   `metadata.studios`, **`metadata.age_rating`** (российский `16+`/`18+`, иначе американский
   `PG-13`/`R`) и **`metadata.trailers`** (YouTube, русские трейлеры первыми).
4. **Поиск (`GET /search`)** больше не находит фильмы по имени участника, по названию тега и по
   тексту описания — только по названию, оригинальному названию и студии. Формат ответа тот же.
5. Фильмография человека (`GET /people/{slug}`) тоже стала длиннее; у многих людей появились
   `bio` (русская биография), `birth_date`, `photo_url` (загрузка ещё идёт).

## Что сделать

### 1. Подписи ролей

Словарь `role` → подпись (единственное / множественное число для заголовков групп):

| `role` | Подпись | Группа |
|---|---|---|
| `director` | Режиссёр | Режиссёры |
| `writer` | Сценарист | Сценаристы |
| `producer` | Продюсер | Продюсеры |
| `composer` | Композитор | Композиторы |
| `cinematographer` | Оператор | Операторы |
| `editor` | Монтажёр | Монтажёры |
| `actor` | Актёр (с `character_name`: «… — Пол Атрейдес») | В ролях |
| `voice_actor` | Озвучивание | Роли озвучивали |
| `author` | Автор | Авторы |
| `creator` | Создатель | Создатели |

Неизвестная роль — показать как есть (`role`), не падать и не скрывать участника.

### 2. Карточка фильма: блок «Съёмочная группа и актёры»

- В шапке карточки — как сейчас: режиссёр(ы) и первые 5–6 актёров.
- Ниже — блок по группам в порядке таблицы. В каждой группе — первые N (актёры — 12, остальные
  роли — 6), кнопка «Показать всех (K)» раскрывает остальных **на клиенте** (данные уже в ответе
  карточки, дополнительных запросов нет).
- Один человек в нескольких ролях (режиссёр и сценарист) — в каждой группе.
- Фото — `person.photo_url`, нет — заглушка с инициалами. Имя — ссылка `/people/{slug}`.
- SSR/статика: в HTML — только видимая часть (первые N), чтобы страница не раздувалась; полный список —
  из того же JSON при раскрытии.

### 3. Возрастной рейтинг и трейлер

- `metadata.age_rating` — бейдж в шапке карточки (`16+`, `PG-13` — как пришло).
- `metadata.trailers` — если ещё не выводится: первый доступный источник (логика выбора провайдера
  уже описана в прошлом промпте карточки).

### 4. Страница человека

- Фильмография: группировать по ролям (те же подписи), внутри — новые сверху; длинные списки —
  «Показать всех».
- `bio` и `birth_date` — показывать, если есть.

### 5. Поиск

- Убрать подсказки вида «ищите по актёрам» (если были). Плейсхолдер: «Название фильма или студия».
- Блок «В архиве» из промпта `frontend-prompt-archive.md` остаётся.

## Проверка

- `pnpm verify` зелёный.
- Руками на dev: «Интерстеллар» (`/films/interstellar`) — все группы, раскрытие «Показать всех»,
  бейдж возраста, трейлер; фильм без титров — блок не показывается; страница режиссёра —
  фильмография по ролям; поиск «интерстеллар» находит фильм, «нолан» — нет (так задумано).
